# Sample data

`meetuniversity_sales_sample.csv` is **synthetic** data generated for the Business Analysis demonstration. It is not real MeetUniversity data. It has 600 leads with the furthest funnel stage each one reached, the product line, channel, region, segment, deal value and owner.

`deal_value_inr` is the potential value of the deal; only rows whose `stage_reached` is `Enrolled` are won revenue.

Put your own CSV files in the app under **Skills & Tools → Data files**, or drop them in `data/uploads/`.
